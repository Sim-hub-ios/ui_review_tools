## SM-B01：历史 Review 行空白区域无法点击

优先级：P2（非阻断，用户可点击标题继续）。

复现步骤：

1. 导入截图创建 Review。
2. 点击“历史 Review”。
3. 点击同一条历史记录标题与右侧箭头之间的空白区域。
4. 再点击该条记录的标题。

实际结果：步骤 3 没有响应，仍停留在历史弹窗；步骤 4 正常打开 Review 并关闭弹窗。已通过坐标点击重复确认，不仅是可访问性行点击失败。

期望结果：整行是统一的点击目标，点击行内空白区也能打开记录。

代码位置：`Sources/UIReview/UtilityViews.swift:16–27`。`Button` 的 label 使用 `HStack + Spacer` 和 `.buttonStyle(.plain)`，没有为整行指定点击形状。建议在 label 上设置 `.contentShape(Rectangle())` 并复测。模拟器列表采用相似结构，也建议检查空白区域；本轮点击其明确的“截图”按钮可以成功采集。
