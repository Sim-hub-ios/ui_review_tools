# V1 本机验证记录

日期：2026-09-05

## 环境

- macOS 26.6.1 / Apple Silicon
- Xcode 26.3.0 / Swift 6.2.4
- 工程最低系统：macOS 14（未在 macOS 14 实机运行）

## 已通过

- Swift Package Debug 与 Release 构建均通过；最终 `.app` 使用 Release 优化二进制。
- 10 项 XCTest：坐标与归一化、保存/重新加载、无效写入保护、损坏数据、路径/符号链接边界、完整导出、失败导出清理、标注 PNG 方向、App 编辑/删除/撤销/重做/重启恢复。
- 17 次真实 stdio JSON-RPC 请求：初始化、5 个只读工具、原图与标注图、缺失/错误参数、未知方法、ping、运行中读取最新文件、损坏数据处理。
- MCP 测试校验了调用前后用户数据字节哈希未改变，并再次针对 `.app` 内的 MCP 可执行文件运行通过。
- App bundle 的 Info.plist 与 ad-hoc 签名验证。

## 原生窗口操作验证

使用 `/private/tmp/UIReview-visual-test/` 内的隔离测试 App 和数据目录。

- 空状态及深色三栏编辑器显示。
- 从 NSOpenPanel 导入测试 PNG，截图数量从 1 变成 2。
- 拖动创建问题矩形；右侧显示原图坐标。
- 中文评论粘贴、自动保存；直接读取测试 JSON 验证落盘。
- 拖动角点缩放后通过 ⌘Z 撤销，显示“已撤销调整区域”。
- 模拟器列表成功列出当前已启动的 iPhone 17。

发现并修复：主窗口的图片粘贴监视器需要排除文件选择模态框和输入控件，避免干扰系统文字粘贴。
自动化工具在原生文件路径浮层使用剪贴板时仍有工具侧超时，改用逐步键入路径完成了导入验证。
