# V1 本机验证总表

更新日期：2026-09-05。汇总当日各轮验证；具体操作和范围见 [冒烟测试记录](smoke-test-2026-09-05.md)。

## 环境

- macOS 26.6.1 / Apple Silicon。
- Xcode 26.3.0 / Swift 6.2.4。
- 工程最低系统：macOS 14，尚未在 macOS 14 实机运行。
- 使用隔离数据进行测试；截图授权补测使用正式 App 身份及独立 `--data-dir`，结束后恢复正式数据会话。

## 自动化与构建

- 最新自动化基线：24 项 XCTest，0 失败；覆盖坐标、保存/加载、无效写入与损坏数据保护、路径边界、导出、标注图方向、编辑撤销、快捷键判定、Agent 安装与检测、历史 Review 删除和恢复、缩略图缓存观察。
- 17 次真实 stdio MCP JSON-RPC 请求通过：初始化、5 个只读工具、原图/标注图、错误参数、未知方法、ping、实时读取及损坏数据处理。
- MCP 校验读取前后隔离数据字节不变；针对 App 包内 Release MCP 的 UI 数据读取也通过。
- Debug、Release 构建通过；最新历史空状态调整后 Release 构建通过。该纯布局调整后未额外重跑全部单元测试。
- App 图标已打包；Info.plist 和 ad-hoc 签名检查通过，并验证 macOS 图标服务读取到新图标。

## 已完成的真实界面验证

| 范围 | 结果 |
|---|---|
| 编辑器 | 深色三栏布局、文件选择导入、创建/移动/缩放矩形、中文评论及自动保存、撤销/重做、重命名、截图删除和恢复通过 |
| 导出与读取 | Markdown、JSON、原图和标注图完整导出；导出与 MCP 标注图一致；App 退出后 MCP 仍可读取 |

| 截图持久化 | 三张系统截图保存，尺寸匹配元数据；MCP 原图逐字节一致；进程退出重启后仍可读取 |
