版本：2.0；初稿日期：2026-09-08；最后校订：2026-10-13。

状态：V2 需求与验收基线，当前交互以 2.0.6（build 9）实现为依据。本文校订不代表重新完成真实界面或设备验收；已记录的验证范围详见 [开发交付记录](UI_Review_V2_Implementation.md)。§17 首次向导仍为待实现需求。

## 1. 产品定位

UI Review 是面向开发者的原生 macOS UI 问题标注与 Agent 交接工具。用户通过截图或录屏指出问题，工具整理位置、时间和评论，将可追溯的视觉证据交给 Codex、Claude Code 等 Coding Agent。

> 截图表达静态位置，视频表达变化过程，框选表达问题区域，评论表达修改要求。

V2 在现有截图审查基础上加入动画审查。只有当前实现录屏也能完成反馈，参考视频是可选增强。框选是常驻、直接可见的核心工具；当前通过框选新建动画问题，随后可以移除区域，保留只描述时间的问题。

产品不分析或修改项目代码，不推断代码位置，不自动判定动画质量，不把主观描述转换成未经确认的参数。模型调用与代码修改由用户自己的 Agent 会话完成。

## 3. 用户场景与完成标准

| 场景 | 用户操作 | 完成标准 |
| --- | --- | --- |
| 静态 UI 不一致 | 截图、框选、评论 | Agent 取得原图、标注图、坐标与原始评论 |
| 动画整体生硬，没有参考 | 导入录屏、选段、框选新建问题、移除区域后描述 | 无区域反馈保留时间和描述，无需参考即可交接 |
| 只有某个组件有问题 | 暂停、框选组件、描述 | 时间、矩形与问题绑定到同一帧 |
| 动画与参考不一致 | 添加参考、分别设起点、同步查看 | 可以观察真实时长差异，标注仍定位当前实现 |
| 离开 App 后继续修复 | 保存、关闭 App、由 Agent 读取 | 独立 MCP 仍能提供已保存证据 |

成功标准是 Agent 能确定“哪份素材、哪个时间、哪个区域、用户希望怎样”，无需用户重新解释截图与录屏对应关系。不以自动生成的参数数量或自动诊断数量衡量价值。

## 4. 范围与优先级

P0 为 V2 首次交付必须完成的范围，不能以原型中的静态替代视为实现。

| 编号 | P0 范围 |
| --- | --- |
| R01 | 保留全部现有截图入口、标注、历史、保存、撤销与交接能力 |
| R02 | 视频文件导入、拖放、混合素材列表、错误与进度状态 |
| R03 | 播放暂停、真实逐帧、0.25×/0.5×/1×/2×、时间轴缩放与选段循环 |
| R04 | 时间点/时间段问题、常驻框选工具、矩形移动缩放与评论 |
| R05 | 可选参考视频、手动起点对齐、并排同步播放 |
| R06 | Review 自动保存、动画操作撤销重做、V1 数据迁移保护 |
| R07 | 只读 MCP 动画与帧读取、直接复制交接提示词、完整文件夹导出 |

后续候选能力：App 内录屏、片段裁剪导出、叠加、像素差异图、自动对齐、运动跟踪、多帧区域轨迹。它们不属于本次开发承诺。

持续排除：AI 自动创建问题、自动识别曲线、代码定位与修改、云同步、团队协作。录屏可以承载交互问题，但 V2 不额外引入独立的用户流程建模模块。

## 5. 工作区与素材管理

### 5.1 布局

延续三栏：左侧素材、中间画布、右侧问题。选中视频时，中间画布底部显示播放控制与时间轴。截图不显示时间轴。

原型基准为 1280 × 820，三栏宽度为 232/728/320。窗口缩小时先调整画布缩放，保留关键操作；最小窗口尺寸与长标题折叠方案在实现前验证，不允许按钮覆盖视频或评论输入区。

画布常驻「选择 V」「框选标记 R」。快捷键在文字输入、弹窗或无可标注素材时不触发。已有截图快捷键及文字编辑行为保持一致。

### 5.2 导入和列表

- 现有图片文件、剪贴板、系统截图与模拟器截图入口保持。
- 视频通过文件选择、拖放或剪贴板文件导入。左侧素材列表获得焦点时，⌘V 将图片或视频导入为新素材；已选动画且素材列表未获焦点时，单个 MP4/MOV 视频文件粘贴为参考，已有参考时提示先移除。文字输入区保留普通粘贴行为。App 内录屏仍不在当前范围。
- 支持 MP4/MOV 中的 H.264 与 SDR HEVC；HDR 暂不支持。可用性依据实际视频轨道验证，不仅根据扩展名判断。
- 导入先验证可解码视频轨道、时长和尺寸，复制到本地资产目录后才发布有效条目。源文件之后移动或删除不影响已导入内容。
- 显示导入中与可取消状态；失败或取消不留下可编辑的半成品，不破坏已有素材。多文件逐项报告结果，成功项保留。
- 第一次有效导入沿用自动创建当前 Review；普通视频导入总是新条目，通过条目内的「添加参考视频」或上述参考粘贴入口建立参考关系。
- 左侧区分截图/动画，显示名称和问题数量。重命名、删除、历史恢复及混合素材顺序持久化。
- 删除动画条目同时移除其问题，支持撤销；引用的资产暂不自动清理。

## 6. 截图审查保留要求（R01）

截图继续使用正向 PNG 原图像素坐标与归一化区域，原点在左上角。每个截图问题保留一个矩形与评论。

保持矩形创建、移动、四角缩放、删除、画布缩放及滚动；空评论保存为待填写状态。删除截图/问题/Review、文本编辑及撤销行为不因视频模块引入而改变。

原图、标注图及截图 MCP 查询不能因 Review 中包含动画而失败。不得把视频要求强加给截图，例如要求时间范围、参考素材或动画分类。

## 7. 动画播放和时间轴（R03）

- 导入完成后暂停于首个可解码画面，音频默认静音；切换素材停止原素材播放。
- 播放速度只改变预览，不修改视频、对齐关系和问题时间。
- 上一帧/下一帧依据实际视频帧时间；兼容不同帧率及可变帧率，不按固定 1/30 秒假定相邻帧。
- 播放头支持定位，时间轴支持放大、缩略帧、问题标记、时间段选择。
- 时间段显示起止时间和时长；合法范围位于视频内，起点早于终点。时间点为独立语义，不用伪造零长度区间代替。
- 「播放此段」循环选段；没有时间段时正常播放。到视频末尾停住，不自动修改选段；再次播放从视频开头重新开始，启用时间段时从该段起点开始。
- UI 显示毫秒或秒；持久化保留媒体时间精度。获取指定时间的画面时记录实际解码时间，不将请求时间冒充帧时间。
- 拖动定位期间可以显示预览；框选只能针对定位完成后的确定帧。未就绪时禁用框选并提示正在加载。

## 8. 动画问题与框选（R04）

### 8.1 新建问题与补充区域

新建路径：暂停或选择时间段 → 点击「框选 R」固定当前帧 → 拖动矩形 → 创建新问题并聚焦描述。已有选段且包含该帧时使用该选段，否则使用该帧时间点。普通框选始终新建问题，即使列表中已选中其他问题，也不覆盖其区域。

要为已有无区域问题补充区域，先选中问题并点击右侧「在当前帧框选」；要替换已有区域，点击右侧「重新框选」，定位到原标注帧后重画。只有这些显式入口才修改已有问题；旧矩形保留至新矩形完成，Esc 取消时恢复原区域。一次重画替换一个区域，不静默创建多个矩形。

当前界面没有独立「添加问题」按钮。需要无区域的时间点/时间段反馈时，先框选新建，再点击「移除区域」，问题、描述和时间均保留。

### 8.2 标记行为

- 首版每个动画问题为零或一个矩形，绑定当前实现的一帧；需要多个区域时建立多个问题。
- 在当前实现的可见视频内容内拖绘，支持任意拖动方向，忽略留白区；矩形不得超出帧边界。
- 最小矩形为正向帧坐标中的 2 × 2 像素，过小操作不生成有效区域。
- 区域显示问题编号和四角手柄；选择模式中支持拖动移动与调整大小，持续操作合并为一次撤销。
- 编号与右侧问题列表对应。编号用于展示，内部稳定 ID 不随排序或删除变化。
- 右侧显示所属视频、标注帧原始时间、矩形坐标及帧尺寸。有区域时提供「查看标注帧」「重新框选」「移除区域」；无区域时提供「在当前帧框选」。
- 移除区域仅移除矩形，保留评论和时间。删除问题使用独立操作。输入框内 Delete 保持文本编辑行为。
- 播放时隐藏可编辑矩形；仅回到标注帧才显示该框，不假装跟踪组件。查看其他帧时仍可通过右侧「查看标注帧」返回。
- 时间段问题的标注帧必须处于范围内；补充或重画已有问题的区域时，若当前帧在范围外，提示跳转回范围内，不静默改变问题时间。普通框选新建时，当前帧不在选段内则创建时间点问题。调整已有问题范围不得隐式排除标注帧，用户可先移除区域再调整。
- 双视频首版仅在当前实现上框选；参考栏清晰标注为参考，不把当前矩形直接套用到不同尺寸的参考视频。

### 8.3 评论与状态

完成反馈所需的唯一文字字段为问题描述；期望、组件名称与分类均可选。分类包括位移、缩放、透明度、速度与节奏、延迟、其他，不自动生成参数。

空评论是待填写问题，允许保存；交接提示词标明待填写数量。点击问题定位到时间点或区间起点；点击「查看标注帧」定位到准确标注帧。评论与区域随自动保存恢复。

## 9. 参考视频和对齐（R05）

添加参考后显示左参考、右当前实现，保持各自宽高比，不拉伸、不自动推断空间比例。

参考对齐直接在主界面完成，两侧视频各有独立时间轴与起点轨道，不再打开对齐窗口。未完成对齐时可独立定位两份原视频；播放/逐帧控制作用于当前聚焦侧。

暂停时在任意一侧的起点轨道设置起点，再设置另一侧起点；两侧齐备后自动保存并应用同步关系，无需确认按钮。只设置第一侧时属于界面草稿，尚未形成保存的对齐关系。

已设置的起点可以在轨道上拖动；拖动期间预览对应关系，松手后保存为一次对齐修改。Esc 取消拖动时恢复拖动前的起点，不保存中间值。播放期间和查看旧问题参考快照时禁用起点编辑。保存的对齐修改支持撤销/重做；首次对齐保存后撤销，在本次运行中回到只设置第一侧的草稿状态。要回到单视频，使用「移除参考」，该操作也可撤销。

相对时间 t 对应当前原始时间 currentStart + t、参考原始时间 referenceStart + t。此关系仅平移时间，不拉伸真实动画时长。界面显示相对时间并保留原始时间读数。

一侧越过文件末尾时保留最后画面并标记「视频已结束」；早于文件开头时显示「此时间无画面」。不能将视频文件结束当作动画结束。

问题以当前视频原始时间为权威位置，并保存适用的参考资产与对齐快照。新起点用于新问题；已有问题通过明确的「使用新的对齐方式」更新，可撤销。检查旧问题时显示其对应关系，不能静默改写证据。

移除或替换参考不删除当前问题，历史参考关系保留可追溯信息，并提示与当前参考不同。交接注明使用哪个参考快照；无法读取历史资产时明确报告缺失，不自动套用新视频。首版不原地替换当前实现视频，应新建条目。

## 10. 数据与持久化（R06）

### 10.1 概念模型

| 对象 | 必须表达的信息 |
| --- | --- |
| Review | 稳定 ID、名称、时间、截图集合、动画集合、混合显示顺序 |
| Screenshot | 现有 ID、原图、正向尺寸、矩形问题 |
| Animation | ID、名称、当前视频资产、可选参考关系、问题集合 |
| VideoAsset | 稳定 ID、本地相对路径、可解码格式、时长、方向、可见帧尺寸 |
| AnimationIssue | ID、当前资产、时间点或区间、描述、可选期望/分类/组件/区域/参考快照 |
| FrameRegion | 当前资产 ID、实际帧时间、正向帧尺寸、像素矩形、归一化矩形 |

这定义信息契约，不强制把现有截图 Issue 改成统一可空字段模型。Swift 类型、JSON 字段名和完整 Schema 在技术设计中冻结。

### 10.2 坐标与时间约束

区域以应用视频方向变换后的可见帧为准，不使用窗口坐标或播放器留白坐标。缩放画布不改变已存区域；归一化值按该帧宽高计算。像素不自动换算为 iOS 点或 Flutter 逻辑像素。

时间和尺寸必须有限、有效、可校验。导出与 MCP 返回相同的素材、问题、区域和时间事实；标注图不得改变原帧方向或标记位置。

### 10.3 保存、迁移和撤销

- 沿用本地数据目录及 App/MCP 共用目录机制，原素材不可变，缩略图等派生资产可重建。
- 编辑自动保存；写入失败保持内存内容并显示未保存状态，提供重试，不假报成功。
- 播放头与预览操作不进入撤销历史；问题增删、时间编辑、矩形、评论、参考关系、素材增删进入历史。
- 沿用当前运行内最多 80 次撤销、相邻文本合并、重启不恢复撤销历史的边界。
- 现有 schemaVersion=1 数据升级前备份；完整验证新结构后原子发布。失败保留原库并停止写入，不用空库覆盖。
- 旧截图 ID、评论、坐标、路径和当前 Review 选择保持。新版读取未知更高版本时应停止写入并提示升级。
- 不承诺旧版 App 能写新版库；发布说明包含回退到迁移前备份的路径，禁止双版本同时写同一库。
- MCP 读取一致的已保存快照；尚未完成复制或写入的资产不对外显示为可用证据。

## 11. Agent 交接与 MCP（R07）

### 11.1 交接范围

工具栏在截取 / 模拟器 / 导入之后固定三个按钮，截图与视频同一套、始终显示：导出 Review、复制整个 Review、复制当前素材（蓝色主按钮）。不因有无动画分叉，也不再弹出交接预览。

复制当前素材只带侧边栏选中的那一张截图或那一段视频；复制整个 Review 带当前会话全部截图与视频，不含历史 Review。两个复制都直接写入剪贴板，提示词包含范围、截图 / 动画 ID、library revision、对应 MCP 工具与待填写数。当前素材 0 个问题仍可复制。没有当前 Review，或截图与动画都为空时，三个按钮禁用。复制与导出前先 flush 保存。

复制不自动发送消息，导出不自动上传。无参考时不输出参考要求；有矩形时必须交付位置证据，不能只复制描述。

### 11.2 最小证据包

- Review/素材/问题稳定 ID、原始评论与可选期望。
- 当前视频标识、原始时间点或区间、时间语义和实际帧时间。
- 如有参考：参考标识、起点快照、映射时间与越界/缺失状态。
- 如有区域：原帧、标注图、帧尺寸、像素与归一化矩形、所属素材和标注帧。
- 时间段的关键帧覆盖开始、中间与结束附近，包含请求和实际时间；必要时由 Agent 继续取帧。重复解码到同一帧时去重并说明。
- 时间点提供该点证据，不宣称单帧能够证明动画速度或曲线。

不填补未知动画参数，不把用户建议标记为工具测量结果。任何缺失、截断或抽帧失败都随结果返回。

### 11.3 MCP 兼容和新增能力

保留 get_current_review、list_reviews、get_review、get_screenshot、get_issues 的现有参数及截图语义。get_screenshot 继续只返回截图，不把视频帧伪装为截图资产。现有截图字段不重命名、不改变类型。

动画发现与读取链路为：列出动画摘要（list_animations）→ 读取条目/问题（get_animation）→ 取指定原帧或标注帧（get_animation_frame）→ 读取有限帧序列（get_animation_frames）。具体参数、Schema 与分页方式见 [V2 技术方案](UI_Review_V2_Technical_Design.md)。

帧序列参数必须有数量、分辨率、响应字节上限；超限返回缩减说明或下一批读取方式，不无限抽帧。客户端不能指定任意磁盘路径，只能通过已登记 ID 访问数据目录内合法资产。服务保持本地只读，App 退出后仍可抽取已保存视频的帧。

## 12. 文件导出

导出永远是整份当前 Review，不再选择范围。纯截图走原有 ReviewExport 包结构；含视频时先用系统警告确认「将导出完整录屏，约 X，另加图片与证据文件」，再选文件夹并用 Motion 导出写完整 review。导出进行中状态栏显示「正在导出 · 取消」，可点取消；成功后在 Finder 中显示文件夹。

导出一个新目录，含 review.md、review.json、图片、视频和帧文件；所有文档资产引用使用包内相对路径，移动目录后仍可读取。

原视频完整复制，导出前显示预计总大小及「包含完整录屏，不仅是标注片段」。包括问题实际引用的参考快照资产，去重保存；不以缩略图替代原始证据。

导出可取消，不覆盖已有目录。缺失资产或生成失败时默认不发布完整成功包；保留原 Review，列出失败项并可重试。清理仅限本次临时导出产物。

## 13. 异常与非功能要求

| 情况 | 用户可见行为 |
| --- | --- |
| 不支持、无视频轨道、损坏文件 | 指明具体素材与原因，允许重新导入 |
| 导入空间不足或复制失败 | 不产生有效条目，已成功项和旧 Review 保留 |
| 定位/抽帧失败 | 说明失败时间，允许重试；禁止在旧画面上标成新时间 |
| 参考未添加 | 单视频正常工作，不提示错误 |
| 参考缺失或对应时间越界 | 显式提示，不补造对照帧 |
| 保存失败 | 未保存状态，保留编辑并支持重试 |
| Agent 未连接 | 保留复制/导出选择，可从「Agent 集成…」设置面板安装或查看配置；首次向导尚未实现，规划见 §17 |
| 导出取消/失败 | 不声称完整成功，不影响原素材 |

导入、抽帧和导出不阻塞主界面；切换素材或取消后，过期异步结果不得覆盖新选择。视频不整段加载为帧数组；派生帧缓存必须有预算和清理策略。进度不确定时不伪造百分比。

关键操作有文字或辅助功能标签；选中问题不能只靠颜色区别。原型示例里的「演示框选结果」不进入正式 App。

## 17. 首次向导：安装 Agent MCP

首次打开空工作区时弹出可跳过的三步向导，主路径是安装只读 MCP。导入素材和复制交接提示词仍走现有空状态与交接流程。

1. 说明：为什么需要 MCP，以及只读、本机、安装后需重新连接。
2. 安装：Codex、Claude Code、Cursor 并排，沿用现有一键安装 / 升级 / 检测；未安装也可继续。
3. 结果：全部成功、部分成功或都未安装。成功后提示在客户端新开会话或重新连接。

约束：

- 任意一步可「暂时跳过」；跳过或完成后不再自动弹出。
- 有素材的工作区不自动弹；本机记录已完成或已跳过。
- 窗口底部「MCP · 只读访问」再次打开同一向导，默认停在安装步。
- 菜单「Agent 集成…」仍打开完整设置面板，含手动配置和复制交接提示词。向导不取代它。
- 只修改用户点击安装的那个客户端；其他 MCP 保留；同名自定义配置不覆盖。

本项尚未实现。安装逻辑复用现有 Agent 安装与检测，不新增写入范围。
