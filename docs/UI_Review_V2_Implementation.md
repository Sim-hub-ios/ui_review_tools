# UI Review V2 开发交付记录

日期：2026-09-08。状态：已生成本机开发版；不等同于全部 PRD 验收完成。

## 功能实现

- 新增独立动画模型、精确媒体时间、时间点/半开时间段、帧区域、参考对齐快照及混合素材顺序。
- V1 库升级前保留原始字节备份；未知版本停止写入。串行保存检测外部修改，失败保留工作副本，支持重试、撤销和退出保护；评论合并保存。
- 新增 ReviewMedia：视频验证与本地复制、取消、真实 PTS 索引、方向变换、精确取帧、内存缓存、区域图和证据导出。
- 视频工作区提供播放、逐帧、倍速、时间点/选段、缩略时间轴、缩放、区域创建/移动/四角调整、重画/移除和问题评论。
- 参考编辑提供两侧独立定位与播放、设置起点、确认/取消；审查时同步播放，保留每条问题的参考关系。
- 新增四个动画 MCP 工具，旧五工具维持截图投影；支持分页、revision、数字参数、并发配额、取消及有界图像响应。客户端检测区分截图和动画能力。
- 交接预览支持当前素材/整个 Review、待填写数、区域图及证据读取错误。导出包含完整视频、区域原帧/标注图、有限关键帧及参考映射信息，通过暂存目录发布。

## 本机开发版

- 主程序：`build/UI Review.app`，包内包含 `ui-review-mcp`，版本 2.0.0，本机 ad-hoc 签名。
- 独立预览包：`build/UI Review V2 Preview.app`。
- 推荐通过 [打开 V2 预览](../scripts/open-v2-preview.command) 启动。此入口显式使用 `build/v2-preview-data`，其中是合成测试素材，与用户原 Review 目录分离。
- 没有替换 `/Applications` 内已安装的应用，没有迁移用户实际数据，没有提交或推送 Git 变更。

## 已取得的验证证据

1. 数据测试覆盖原始字节备份、只读加载不迁移、未知版本拒绝覆盖、外部写者冲突、半开时间段及有理数比较。
2. Store 测试覆盖旧截图流程、保存失败保留评论、评论延迟保存、动画库重开选择、删除/撤销恢复。
3. 媒体测试使用 T0 合成样本：30 fps、VFR、90 度旋转、1080p/60 fps；验证真实时间索引、精确帧、方向尺寸、区域图和导出路径。
4. 新增 HEVC SDR 合成样本可解码测试。此结果不能替代 iPhone/Android 真实录屏兼容性验证。
5. 连续定位与双播放器运行测试验证最后一次定位生效、两侧准确暂停帧和实际播放推进；发现并修复播放器未 ReadyToPlay 就请求同步播放的崩溃。
6. 已打包 MCP 通过旧截图协议 17 次请求、动画协议 11 次请求，以及独立包内握手。读取测试没有修改库。
7. 已验证本机包签名和 `git diff --check`。

最终回归执行 35 项测试，0 失败、0 跳过（显式排除 1 项真实客户端安装测试）；日志位于本机 `/tmp/ui-review-v2-final-tests.log`。真实客户端安装测试不作为本轮执行项，避免将“工具握手通过”混同于修改用户客户端配置。

## 必须保留的验收边界

- 桌面自动化两次读取测试窗口发生严重延迟；设置 20 秒超时仍等待约 28 分钟才返回。因此本轮没有完成实际鼠标绘制、缩放、Esc、窄窗口及深色主题的逐项视觉验收。窗口读取成功不是这些交互已通过的证据。
- macOS 14 与真实 iPhone/Android/模拟器录屏矩阵待验；本机测试环境不能证明所有最低系统版本行为。
- HDR 明确拒绝，暂不做自动色调映射或转码。HEVC 当前仅有 SDR 合成样本结果，复杂编辑轨道、clean aperture、长 GOP 等仍需要扩展样本。
- 10 秒同步误差曲线、100 次切换资源稳定性、严格冷缓存性能尚未完成，不能引用早先 T0 合成探针的结果冒充生产 UI 性能。
- 完整 PRD A01–A17 验收仍需覆盖上述真实界面与设备场景。当前交付是可运行的开发版，不是可对外发布的正式版本。
