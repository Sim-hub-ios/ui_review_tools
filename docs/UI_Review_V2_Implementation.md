# UI Review V2 开发交付记录

初版日期：2026-09-08。文档核对日期：2026-10-13。

本文保留 2026-09-08 初次开发交付的历史记录，并单列截至 2.0.6（build 9）的代码现状。历史测试结果不代表当前版本已经重新执行相同测试或完成全部 PRD 验收。

## 截至 2.0.6（build 9）的现状

- 版本基准来自 `Resources/Info.plist`；[2.0.6 发布记录](releases/UIReview-2.0.6.md) 已记录主界面对齐、素材列表粘贴、播放结束后重播和 Agent 修复交接等变化。
- 动画持久化模型包含 `referenceAssetID`，可先添加参考视频再设置对齐；`activeReference` 表示已保存关系。主界面两侧时间轴设置完起点后自动保存，拖动起点在结束时更新关系，没有独立确认窗口；旧问题仍保留创建时的参考快照。
- 普通视频框选创建新问题，绑定当前帧或已选择的时间段；已有问题的区域通过“重新框选”修改，无区域的问题使用“在当前帧框选”。当前面板没有单独的“添加问题”按钮。
- 工具栏直接提供“复制当前素材”“复制整个 Review”“导出 Review”，没有交接预览。两个复制按钮分别限定提示词范围，导出仍包含整个 Review；含动画时提示将导出完整录屏。提示词要求 Agent 读取证据后直接按评论修改当前项目，待填写项先跳过。
- 视频支持 MP4/MOV 中的 SDR H.264 与 SDR HEVC；检测到 PQ/HLG HDR 时拒绝，不做自动色调映射。真实录屏兼容性与性能仍受下列验收证据边界约束。
- 四个动画 MCP 工具保留旧截图工具投影；帧元数据实际使用 `sourceWidth/sourceHeight/renderedWidth/renderedHeight`，没有 scale 字段。单帧和多帧均返回 frames 清单及 requestedCount/returnedCount/failedFrames/warnings；多帧去重或部分失败时，调用方必须检查返回是否完整。缓存、预算降级和原设计的差异见 [技术方案第 5、8 节](UI_Review_V2_Technical_Design.md)。
- 删除动画会清理无引用的视频资产元数据，原视频物理文件不自动删除，撤销可以恢复元数据；仍被旧问题快照引用的参考会保留。

## 当前本机预览入口

- [构建脚本](../scripts/build-app.sh) 生成 `build/UI Review.app`，包内包含 `ui-review-mcp`，采用本机 ad-hoc 签名；版本由 `Resources/Info.plist` 决定。
- 通过 [打开 V2 预览](../scripts/open-v2-preview.command) 启动上述 App，并显式使用 `build/v2-preview-data`。缺少构建包时先执行 `bash scripts/build-app.sh`。
- 当前入口不依赖 `build/UI Review V2 Preview.app`，也不会自动生成合成测试素材；首次使用空预览目录时需自行导入素材。预览数据与默认用户 Review 目录分开。

## 2026-09-08 原开发交付记录

当次状态为已生成本机 2.0.0 开发版，不等同于全部 PRD 验收完成。以下是当时的功能与产物记录；其中确认/取消对齐和交接预览已被上面的当前行为替代。

### 当时的功能实现

- 新增独立动画模型、精确媒体时间、时间点/半开时间段、帧区域、参考对齐快照及混合素材顺序。
- V1 库升级前保留原始字节备份；未知版本停止写入。串行保存检测外部修改，失败保留工作副本，支持重试、撤销和退出保护；评论合并保存。
- 新增 ReviewMedia：视频验证与本地复制、取消、真实 PTS 索引、方向变换、精确取帧、内存缓存、区域图和证据导出。
- 视频工作区提供播放、逐帧、倍速、时间点/选段、缩略时间轴、缩放、区域创建/移动/四角调整、重画/移除和问题评论。
- 参考编辑提供两侧独立定位与播放、设置起点、确认/取消；审查时同步播放，保留每条问题的参考关系。
- 新增四个动画 MCP 工具，旧五工具维持截图投影；支持分页、revision、数字参数、并发配额、取消及有界图像响应。客户端检测区分截图和动画能力。
- 交接预览支持当前素材/整个 Review、待填写数、区域图及证据读取错误。导出包含完整视频、区域原帧/标注图、有限关键帧及参考映射信息，通过暂存目录发布。

### 当时的本机开发产物

- 主程序：`build/UI Review.app`，包内包含 `ui-review-mcp`，版本 2.0.0，本机 ad-hoc 签名。
- 当时记录了独立预览包 `build/UI Review V2 Preview.app`，以及位于 `build/v2-preview-data` 的合成测试素材；这些本机产物不是当前构建脚本的输出保证。
- 当次交付没有替换 `/Applications` 内已安装的应用，也没有迁移用户实际数据；“没有提交或推送”描述的是当次操作，不代表项目截至 2.0.6 的发布状态。

### 当时已取得的验证证据

1. 数据测试覆盖原始字节备份、只读加载不迁移、未知版本拒绝覆盖、外部写者冲突、半开时间段及有理数比较。
2. Store 测试覆盖旧截图流程、保存失败保留评论、评论延迟保存、动画库重开选择、删除/撤销恢复。
3. 媒体测试使用 T0 合成样本：30 fps、VFR、90 度旋转、1080p/60 fps；验证真实时间索引、精确帧、方向尺寸、区域图和导出路径。
4. 新增 HEVC SDR 合成样本可解码测试。此结果不能替代 iPhone/Android 真实录屏兼容性验证。
5. 连续定位与双播放器运行测试验证最后一次定位生效、两侧准确暂停帧和实际播放推进；发现并修复播放器未 ReadyToPlay 就请求同步播放的崩溃。
6. 已打包 MCP 通过旧截图协议 17 次请求、动画协议 11 次请求，以及独立包内握手。读取测试没有修改库。
7. 已验证本机包签名和 `git diff --check`。

当次最终回归执行 35 项测试，0 失败、0 跳过（显式排除 1 项真实客户端安装测试）；原记录日志位于本机 `/tmp/ui-review-v2-final-tests.log`。该临时日志可能已被清理，不能作为随仓库永久保留的证据。本次文档修订未重跑这些测试。真实客户端安装测试不作为当次执行项，工具握手通过不等于修改用户客户端配置或真实客户端安装通过。

### 当时未完成的验收与当前证据边界

- 当次桌面自动化两次读取测试窗口发生严重延迟；设置 20 秒超时仍等待约 28 分钟才返回。因此当次没有完成实际鼠标绘制、缩放、Esc、窄窗口及深色主题的逐项视觉验收。窗口读取成功不是这些交互已通过的证据。
- 当次 macOS 14 与真实 iPhone/Android/模拟器录屏矩阵未完成；本机测试环境不能证明所有最低系统版本行为。本次修订没有补充该矩阵的新验收结果。
- HEVC 的历史验证是 SDR 合成样本；复杂编辑轨道、clean aperture、长 GOP 等仍需要扩展样本。当前支持 SDR HEVC 与明确拒绝 HDR 的行为，不能推导为全部设备素材都已验收。
- 当次 10 秒同步误差曲线、100 次切换资源稳定性、严格冷缓存性能未完成；本次也没有补充这些结果。早先 T0 合成探针不能用作生产 UI 性能结论。
- 完整 PRD A01–A17 验收需要上述真实界面与设备场景证据。项目已有 2.0.6 发布记录；发布状态与这些专项验收是否完成分别判断。
